# OptiCore.jar

`OptiCore.jar` is the primary engine powering the OptiCore optimization suite. Transitioning from interpreted scripts to a native Java architecture, this plugin provides direct, low-level integration with the Minecraft server environment.

## Overview
Engineered for high-performance Paper and Purpur-based servers, `OptiCore.jar` removes the overhead of external interpreters, ensuring your server maintains a stable 20 TPS even under heavy load.

## Core Features
* **Native Java Execution:** Compiled code for maximum CPU efficiency.
* **Streamlined `config.yml`:** A modern, validated configuration system that is easier to manage and less prone to syntax errors.
* **Modular Design:** Functions as a standalone plugin—simply drag, drop, and configure.
* **Hot-Reloading:** Apply configuration changes without requiring a server restart.

## Technical Specifications
| Attribute | Specification |
| :--- | :--- |
| **Language** | Java (Compiled) |
| **Compatibility** | Paper, Purpur (1.16+) |
| **Deployment** | Standalone `.jar` file |
| **Dependency** | None (Native) |

## Quick Start
1. **Download:** Obtain the latest `OptiCore.jar` release.
2. **Install:** Upload to your `/plugins` directory.
3. **Initialize:** Restart your server.
4. **Configure:** Edit the generated `config.yml` to suit your server's hardware and player load.
