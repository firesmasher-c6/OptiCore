# OptiCoreMC
**The ultimate optimization suite for Minecraft Paper and Purpur servers.**

OptiCoreMC is a collection of high-performance configurations, optimized scripts, and utility tools designed to keep your server running at a solid 20 TPS, even on budget hardware.

---

## 🚀 Key Features
* **Proactive Chunk Management:** Intelligent system to keep your world responsive.
* **Redstone Throttling:** Detects and limits laggy redstone clocks automatically.
* **Entity AI Optimization:** Reduces CPU overhead without sacrificing gameplay mechanics.
* **Low-Overhead:** Designed to be lightweight, utilizing minimal system resources.

## 📥 Installation
1. Download the latest release from the repository.
2. Upload the files to your server directory.
3. Restart your server.
4. Run `/opticore reload` to apply optimizations.

## 🛠 Compatible Platforms
* **PaperMC** (All versions)
* **Purpur** (Recommended)
* **Spigot** (Limited support)
