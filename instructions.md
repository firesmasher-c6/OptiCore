# 1. INSTALLATIONS GUIDE.
> 1.1: Installation:
> When Installing The Pack From Github, always remember to save a backup of your server;
    This can overwrite your gamerules in all worlds. To disable this, **stop** your server;
    Head Over To OptiCore.yml at home/plugins/OptiCore/OptiCore.yml. This holds some gamerules;
    delete this file IF YOU WANT YOUR GAMERULES TO STAY;
    When you finished deleting this file, Check out home/plugins/Skript/scripts/OptiCore.sk This processes all gamerules,
    Inside OptiCore.sk delete the gamerules logic, at the top part.
*Note: Only do this if you want to disable skript from applying those gamerules.*

> 1.2: Installation V2:
> To Install Or Update To A New Version Of OptiCoreMC start your server and execute **/version**
    If it gives you a new update available, Simply check out our discord or head over to the website and check for the release.
    If you cannot find it, Go to the github repository and to releases and check out the new release.

> 1.3: Custom Build Update:
> If you bought custom builds you get free updates.
    To update your custom build, please DM the head developer and ask for an update. Give them your update codes.
        - When you buy a custom build or got one for free, We give you update codes and these codes wont expire, you use those codes to be able to update your custom build.
> If you dont have any codes left, You will buy more codes for updates.
    Or you can directly buy the lastest build and we'll not provide a new free update codes when you already bought a custom build.
    We will give 15% to 45% discount!

> 1.4: Super Optimized Installation:
> If you bought a super optimized build, this will likely contain:
    Server configuration and Server YAMLS such as: spigot.yml, paper-global.yml, etc.
> To install this, create a backup and download it, upload the build you bought, and extract it.
    If you buy a build for Purpur You will likely get,
        - purpur.yml, spigot.yml bukkit.yml, and a config folder with paper-global.yml and paper-world-defaults.yml.
    Now these are the optimizations, it could had reduced mob spawning.

> 1.5: OptiPack Installatiom:
> OptiPack is the datapacks, Made By The OptiCoreMC Dev Team.
    OptiPack has two types:
        - Entities And terrains.
        > OptiPack Entities optimizes mobs on each loaded chunk, For example: This chunk has 5 zombies dont let it spawn more zombies here!
        > OptiPack Terrains is the worldgen chunk generator, this is compatible with pregenerating,
            The terrains edition lets you generate chunks much faster.
